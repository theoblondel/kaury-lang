# Examples

Each folder is one site: a `site.kaury` file and a `public/` folder with its images.

```bash
npm run kaury -- dev examples/lina/site.kaury
```

| Folder | What it is | What it shows |
|---|---|---|
| `lina/` | Chez Lina, the home page of a restaurant | a light page led by photography: an unequal hero with a picture pinned over another, tabs that filter a menu, a card that stays in view, a form sent by e-mail |
| `forge/` | Forge, the home page of a strength gym | a dark page led by oversized type: a headline over a shaded photograph, a ticker, a list with dividers, pictures in black and white that take their colors on hover, prices that follow a monthly or yearly choice |
| `nuit/` | Nuit, the launch page of a perfume | one object in three dimensions that follows the mouse, notes that change the picture when you point at them, a statement over a picture, a one-field list |
| `terre/` | Terre, the shop of a ceramics studio | a shop: pieces filtered by kind, one page per piece made from a list, a basket kept in the browser, functions |
| `relay/` | Relay, the page of a delivery tool | no photograph: a product panel drawn in Kaury, figures and bars that follow a choice, prices by team size |
| `crush/` | Crush, a complete immersive site | three pages, a scene in 3D, a cart kept in the browser |
| `hello/` | the smallest site | one page, one state, one button |

The five designed sites (`lina`, `forge`, `nuit`, `terre`, `relay`) were written with the design rules of `docs/skills/kaury-taste/SKILL.md`: one line that reads the brief, three dials, one accent, one radius, a layout family used once per page. They pass `kaury check` with no warning. `preview.jpg` is their first screen.
